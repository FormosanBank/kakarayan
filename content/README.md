# Reviewed learning content

This directory is the publication boundary for reviewed grammar notes, lessons, paradigms,
and usage guidance. Corpus examples and machine output are not lesson content.

Add an entry to `manifest.json` only after it has:

- A stable identifier and target language or dialect scope.
- An author and named reviewer.
- A completed review date.
- Public source citations.
- A reviewed rights decision and evidence.
- Content in each interface language it claims to support.

The manifest intentionally starts empty. Kakarayan shows an evidence explorer and a
contribution path until reviewed material exists. Do not add generated filler or infer
prescriptive rules from corpus frequencies.
