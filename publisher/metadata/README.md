# Reviewed publication metadata

This directory contains small, reviewed overlays for presentation and rights decisions.
It is not a corpus source.

`rights.json` may override a corpus only after a maintainer has read the central terms, the
corpus README, XML-root notices, and relevant media or dataset cards. Each override must
keep evidence URLs and record its review date. An absent override remains
`review_required`, which prevents the publisher from inventing bulk-redistribution rights.

Public model metadata is collected from the official Hugging Face API during an explicit
publication build. Private repositories, private datasets, and private endpoint credentials
are outside the publisher boundary.
